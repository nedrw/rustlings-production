# 网络即数据：turmoil 拓扑、种子，以及一次运行的摘要

## 为什么

这个 track 的每一步，都靠*调用*来测一条规则——一次投票、一次提交、一次重定向。没有一步测过规则遇上
一个不守规矩的网络时会怎样：一个与别人隔开的节点、一次半途的崩溃、一条永远到不了的消息。分布式系统
*正是*为这类失败而生，而它们也最难测，因为在生产里，它们总在没人挑的时刻发生。

这一步的答案，是每一个正经的分布式系统最终都会走到的那一个：**把失败变成输入。** 一个情景变成一份
文本文件——一份记着故障与写入的*剧本*；种子决定事件发生的顺序；于是一次运行成为 `(seed, playbook)`
的函数。

两条性质随之而来，而两条都是重点：

- **同一个种子是同一次运行。** 一个种子挑出来的 bug，是别人能逐字节复现的 bug。没有这一条，负载下的
  一次失败就只是一段无从查证的轶事。
- **另一个种子是另一次运行。** 一种交错只测一种交错。课程交付的情景要在好几个种子下跑，而不变量得在
  所有这些种子下成立。

这件事能成，全在 `5.3` 做出的那个设计决定，此后每一步都守着它：集群的规则是一台*纯*状态机。剧本只能
驱动一个收消息、回消息的东西。一个在规则内部伸手去够网络的系统，剧本驱动不了——它的失败只能靠等。

（课程也附带 `turmoil`，它在真实 socket 和虚拟时钟这一层做同一件事，`5.3` 的仪器用的就是它。这一步讲
的是失败的*形状*，不是哪个模拟器提供时钟：剧本是数据，而数据比运行过它的工具活得久。）

## 任务

- `src/sim.rs`——这一步新增的模块：
  - `Fault::{Partition, Heal, Drop, Crash, Restart}`，每行解析一个；
  - `Playbook`：按顺序排好的步（`Step::Fault` 和 `Step::Write`），从带 `#` 注释的文本里读出，外加
    `check()`——什么都不说的剧本被拒绝（一个与自己隔开的节点、一次没有分区的愈合、一次丢零条、两次
    崩溃之间没有重启）；
  - `run(seed, size, &playbook)`：集群就是 `size` 台状态机，故障施加在写入之间，每个事件都被记下；
  - `Transcript`：按顺序记下的事件，外加它们的一个摘要（FNV-1a），于是"同一次运行"只需一次比较。
- `docs/simulation.md`——这一步交付的页面（`links` 判它）。
- `tests/sim_playbook.rs` 是课程内容：`slow:sim@3` 闸门跑的那个情景，从一个字符串建起。

## 完成标准

```sh
cargo test -p meshkv --test spec_deterministic_network      # the seven cases
KILN_SIM_SEED=1 cargo test -p meshkv --test sim_playbook -- --nocapture
```

第二条打印剧本的形状、按顺序的每一个事件，以及摘要；同一个种子打印同一个摘要，另一个种子在同一个情景
上打印另一个。

## 陷阱

- **什么都不说的剧本被拒绝。** `partition n1 n1`、没有分区在先的 `heal`、`drop
  0`、两次崩溃之间没有重启——每一条都是改变不了任何事的步，拿它们搭出来的情景什么都证明不了。检查跑在
  运行之前。
- **同一个种子必须是同一次运行，否则这工具就是个传闻。** 摘要正是为这件事，而每个事件之所以只是一个
  名字、一个计数或一个裁决，也出于同一个理由——运行记录里混进一个时钟或一条路径，这条性质就毁了。
- **另一个种子必须是另一次运行。** 一个无视种子的装置跑三次都通过，却什么都证明不了；`sim@3` 要求
  至少两份不同的运行记录。
- **故障在写入之间，不在它们四周。** 最后一次写入之后的崩溃，与它之前的崩溃是两个情景——剧本的顺序
  *就是*情景。
- **词汇小是故意的。** `Partition`、`Heal`、`Drop`、`Crash`、`Restart` 足够表达这个 track 需要的
  每一种失败；一套谁都穷尽不了的故障词汇，只会把 bug 藏起来，而不是找出来。

## 延伸阅读

- `turmoil` 和 `madsim` 是 Rust 里通常用来搭这个想法的两台模拟器；`5.3` 的仪器在 socket 这一层用
  turmoil，而这一步的剧本把同一个想法抬高一层——故障成了文件。
- `5.14` 从剧本里读出一场分区，断言少数派做了什么；`5.16` 把这套词汇变成一张矩阵，每个格子一个预期
  行为。
